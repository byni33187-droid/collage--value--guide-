大学生活指南

这里收录适合中国本科在校生的实用生活经验，帮助大家解决大学生活中的常见问题。

内容分类

1. 生活技巧与宿舍生存

宿舍收纳、清洁、洗衣、物品维护及日常生活小妙招。

2. 省钱与消费决策

生活费管理、购物避坑、学生优惠、免费软件和实用工具。

3. 学习与校园办事

选课、学分、补考、奖助学金及校园常见办事流程。

4. 宿舍相处与人际关系

室友沟通、卫生分工、合理拒绝和人际边界。

5. 校园权益与安全

兼职避坑、消费维权、网络安全和校园求助渠道。

6. 大学成长与个人管理

时间管理、学习习惯、实践活动和个人发展。

收录原则

* 内容具体、实用，尽量提供可以直接执行的步骤。
* 涉及校规、政策和权益时，优先引用可靠或官方来源。
* 说明适用条件，不把个人经验当成普遍结论。
* 对容易过时的信息注明来源和核验日期。
* 尊重不同学校、地区和家庭经济条件的学生。

参与贡献

欢迎本科生分享经验、补充资料和纠正错误信息。提交的内容应尽量真实、清晰、可核实，并保护个人隐私。
