
高性价比大学生指南

帮助本科大学生降低生活成本、提高生活质量、解决校园生活中的实际问题。

我们希望通过开源共建的方式，让大学生活更省心、更实用、更有价值。

🎯 项目面向谁？

本项目主要服务于中国本科在校大学生，包括普通本科、民办本科、公办本科、985 和 211 高校的学生。

不以学校层次区分用户，尽可能让不同地区、不同经济条件的学生都能从中受益。

当前暂不建设专科、专升本和研究生专项内容。

📚 我们分享什么？

* 生活技巧： 宿舍收纳、清洁、洗衣及日常生活小妙招。
* 省钱指南： 生活费管理、购物避坑、学生优惠与免费资源。
* 校园办事： 选课、学分、奖助学金及常见办事流程。
* 人际相处： 室友沟通、社交边界与矛盾处理。
* 权益与安全： 兼职避坑、消费维权、网络安全。
* 大学成长： 时间管理、学习方法、实习与个人发展。

📌 内容原则

1. 实用优先，尽量提供可以直接执行的方法。
2. 尊重事实，涉及校规和政策时优先引用官方来源。
3. 标明适用范围，避免把个人经验当成普遍结论。
4. 对重要信息注明来源和更新时间。
5. 不以学校层次、家庭经济条件评价学生。
6. 欢迎纠错、补充和共同维护。

🤝 如何参与？

欢迎本科大学生分享经过整理的经验、补充可靠资料、纠正错误信息。

我们希望把零散的大学生活经验，逐步整理成一个公开、可靠、方便查阅的实用指南。
